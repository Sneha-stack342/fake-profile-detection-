# 🛡️ Fake Profile Detection on Social Media

A web application that uses **Artificial Intelligence (AI)** and **Machine Learning (ML)** to detect whether a social media profile is **Real** or **Fake**. The system analyzes profile information and predicts the authenticity of the account.

## 🚀 Features
- AI & Machine Learning-based profile detection
- Detects fake and genuine social media accounts
- Responsive and user-friendly interface
- Fast prediction results

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- Scikit-learn
- Machine Learning
